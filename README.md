AI Study Assistant

An AI-powered Study Assistant built with "Gradio" and the "Google Gemini API". It provides clear explanations in "Friendly" or "Academic" mode to match different learning styles.

Features
- Gemini AI integration
- Friendly & Academic personalities
- Simple Gradio interface
- Fast and interactive responses

Tech Stack
- Python
- Gradio
- Google Gemini API

 Run
```bash
pip install -r requirements.txt
python app.py
```

Set your `GEMINI_API_KEY` environment variable before running the app.
